# Suggested demo.mp4 recording order

Record at 1080p with clear audio. The assignment asks for feature demonstration, not a theoretical lecture, so keep narration practical.

1. Home: Light/Dark, responsive resize, New/Best + 3 category product sections.
2. Catalog: pagination, search, brand/price/rating filters, 4 sorts.
3. Detail: 3 images, 2 variants, dynamic stock/price, comment/rating realtime with second window.
4. Cart: add/update/remove without reload.
5. Guest checkout: address, SAVE5 preview, payment, success page, Mailpit email.
6. Login customer: profile, multiple addresses, purchase history/order status, loyalty points.
7. Password recovery: Mailpit reset email (briefly).
8. Admin: simple dashboard, advanced period switching, product/category/stock management, users, order filters/details/status, discount management.
9. Scaling evidence: `docker compose ps`, `/health` response / instance header, explain web1+web2 behind Nginx in one short sentence.
10. End on working homepage/public URL or Docker store.

Avoid spending video time reading source code unless the instructor specifically asks.
